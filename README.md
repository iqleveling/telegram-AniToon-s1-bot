# Telegram AniToon S1 Rename Bot

Fast Telegram file renaming bot.

## Level 1

- Receive files
- Ask for a new filename
- Rename files
- Send renamed files back
- Render Free Web Service support
- Progress display
- `/start`
- `/help`
- `/cancel`

## Environment Variables

Configured in Render:

- API_ID
- API_HASH
- BOT_TOKEN
- OWNER_ID
- FORCE_SUB_CHANNEL
- LOG_CHANNEL
- MONGO_URI
